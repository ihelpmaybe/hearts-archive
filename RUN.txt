Heart’s Archive — Press (this ZIP)

1. Double-click START.cmd  (Windows)
   or: chmod +x START.sh && ./START.sh  (Mac/Linux)
2. Your browser opens http://127.0.0.1:5177/
3. Connect a Pulse wallet → Write → Publish
4. Open your story → Buy A1 if you want the front page (PLS)

Leave the black/terminal window open while you use it.
Close it to stop.

No Node install. This copy only changes when YOU download a newer release.
Demo peek (not locked): https://ihelpmaybe.github.io/hearts-archive/

Money paths: SECURITY.md
Rights: LICENSE (proprietary — not open source)

Stuck?
- Port 5177 already in use → close the other Press window, or set PORT=5180 (START.sh) / edit scripts\serve-dist.ps1 -Port
- “No built Press” → you opened the source repo; download hearts-archive-press.zip from Releases instead
- Browser blank → leave START running; open http://127.0.0.1:5177/ manually
